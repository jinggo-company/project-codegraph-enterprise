# CodeGraph Enterprise

团队级代码知识图谱管理平台 — 基于 [colbymchenry/codegraph](https://github.com/colbymchenry/codegraph) 构建

## 概述

CodeGraph Enterprise 是面向中小研发团队的代码知识图谱 SaaS 平台，提供集中索引管理、CI/CD 预构建索引、跨项目搜索、角色权限、审计日志。
