### 阻塞性 Bug

**BUG-1: pino-pretty 缺失依赖**

`apps/api/src/server.ts` 在 `NODE_ENV=development` 时引用 `pino-pretty` transport，但该包未列入 `package.json` dependencies。导致 API 启动即抛出：
```
Error: unable to determine transport target for "pino-pretty"
```
**严重性**: 高 — 开发者无法从零启动 API 服务
**修复建议**: 在 `apps/api/package.json` 中添加 `"pino-pretty": "^9.0.0"` 到 devDependencies

**BUG-2: Index 表 updatedAt 列迁移失败**

PR 新增 `updatedAt DateTime @updatedAt` 到 Index model，但表中已有 1 行历史数据。Prisma 拒绝自动添加 NOT NULL 列。
**严重性**: 中 — 生产环境有数据时 db push 会失败
**修复建议**: 改为 `updatedAt DateTime @updatedAt @default(now())` 或使用 `prisma migrate` 而非 `db push`
