### 构建失败详情

`apps/api/src/modules/search/index.ts` 第 12 行从 mcp-server 包通过相对路径导入 `CrossProjectEngine`：

```typescript
import { CrossProjectEngine } from '../../../../mcp-server/src/index-engine/cross-project.js';
```

api 的 tsconfig.json 设置 `rootDir: "src"` 且 `include: ["src"]`，跨包相对路径违反了 TypeScript 约束：

```
error TS6059: File '.../mcp-server/src/index-engine/local.ts' is not under 'rootDir'
error TS6307: File '.../mcp-server/src/index-engine/local.ts' is not listed within the file list
```

**影响**: 生产环境无法构建部署。开发环境 (tsx/vitest) 因不使用 rootDir 检查可正常运行。

**修复建议**: 应将 `CrossProjectEngine` 移至共享包（如 `packages/engine`），或通过 `@codegraph/mcp-server` workspace 引用导出。

## 代码审查发现

### 高严重度

1. **API 端点缺少 await** (搜索模块): `searchAcrossProjects`、`searchFulltextAcrossProjects`、`searchCallersAcrossProjects`、`searchRoutesAcrossProjects` 均为 async 方法，但 API handler 未 await，导致 `TypeError: ...map is not a function`。
2. **构建失败**: `apps/api` 通过相对路径跨包导入 `mcp-server/src/index-engine/cross-project.js`，违反 TypeScript `rootDir` 约束，生产构建无法通过。

### 中严重度

3. **Zod 验证错误返回 500 而非 400**: 输入验证失败时，Fastify 未配置 zod 错误的标准化响应处理，导致客户端收到 500 而非 400 Bad Request。

### 低严重度

4. **SQL 注入测试返回空响应**: 含特殊字符的查询可能导致 Fastify 路由解析异常，需确认是否服务端崩溃。
5. **测试用例缺少对 API 端点的 E2E 测试**: `f5.test.ts` 仅测试 MCP 工具层和引擎层，未覆盖 REST API 端点集成测试。

## 结论

**qa_passed: false**

F5 跨项目搜索功能的核心引擎（`CrossProjectEngine`）和 MCP 工具层实现正确，单元测试全部通过。但存在两个阻塞性缺陷：

1. **REST API 端点 `/api/organizations/:orgId/search` 无法正常工作** — async 方法缺少 await，返回 500 错误
2. **生产构建失败** — TypeScript rootDir 约束违反

这两个缺陷使该功能无法在实际环境中部署和使用。通知全丞修复后重新提交验收。
