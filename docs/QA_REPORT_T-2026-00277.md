## 破坏性测试

### DT-01: 审计日志不可篡改
- **结果**: ✅ PASS — 仅注册 GET 路由，无 PUT/PATCH/DELETE。代码注释明确声明 `no PUT/PATCH/DELETE routes for audit logs — they are immutable`

### DT-02: 审计写入失败不阻塞主流程
- **结果**: ✅ PASS — `build-index.ts` 的审计写入在独立 try/catch 中，失败仅 console.error

### DT-03: CSV 注入防护
- **结果**: ✅ PASS — 全丞已在 commit `ae7e2fe` 中修复，`csvEscape()` 对 `=`, `+`, `-`, `@` 开头的值添加 `\t` 前缀。使用 `/^[=+\-@]/.test(str)` 正则匹配

### DT-04: 导出上限保护
- **结果**: ✅ PASS — 10,000 条硬编码上限，防止数据滥用

### DT-05: 多租户隔离
- **结果**: ✅ PASS — 所有查询和导出都以 `organizationId: orgId` 作为 where 条件
